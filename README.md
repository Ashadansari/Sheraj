# Sheraj Alam — Civil Engineer

A responsive civil engineering portfolio built with semantic HTML, CSS and vanilla JavaScript. It uses no frontend or CSS framework.

## Run locally

From this directory, start a static server:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Project structure

- `index.html` — page content, navigation, contact links and metadata
- `css/style.css` — dark visual system, layout, responsive rules and reduced-motion support
- `js/script.js` — floating navigation, scroll reveals, skill carousel, project filters and contact form behavior
- `assets/images/sheraj-alam.webp` — supplied portrait
- `assets/icons/favicon.svg` — site favicon

## Editable content

The education details shown are B.Tech Civil Engineering at JNTU, Anantapur, with graduation year 2028. The displayed engineering knowledge and software tools were supplied as confirmed skills.

Project tiles remain clearly marked placeholders. Replace their titles, descriptions, locations, tools and sample images only when genuine project material is available. The contact form validates fields and opens the visitor’s email application with a prepared draft; it does not send or store submissions.
